# Wedding Gift Manager

## Ultimate Aspiration
The goal of this project is to create a basic registry and tracking tool for wedding gifts. It should allow a couple to list gifts, allow guests to mark them as purchased, and suggest alternatives like sending money if all gifts are taken or known left in price range.

## Why It’s Interesting
I have just recently gotten engaged, and I wanted to use my newly learned skills to make my own personalized registry.I also didn't know something like this already existed. Since managing wedding gifts is something most people encounter creating a software to streamline the process is useful and relatable. I chose this project to apply programming concepts to a real-world problem.

## What I Completed
For this submission, I implemented:
- Gift registration using arrays
- Tracking purchases and buyers
- Option to handle full registry ("just send money")
- A simple menu-driven user interface
- Two tested methods: `AddGift()` and `MarkAsPurchased()`


## Reflection
I learned how to structure a project using parallel arrays and procedural design. Writing tests helped me think through edge cases, and building user feedback loops and made the program feel more complete. I also improved my skills in commenting and structuring my code for readability.
